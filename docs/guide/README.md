# Human Project Guide

This documentation is primarily for the human owner.

Rules:
- Maintain after meaningful architectural/product changes.
- Do not load into routine agent context by default.
- Explain systems in clear human language.
- Prefer diagrams and conceptual explanations over line-by-line code duplication.
- Record the commit/revision against which important sections were verified.

## Suggested sections

- What this project is
- How to run it
- Architecture overview
- Major subsystems
- Data flow
- Storage / database model
- External integrations
- Extension points
- Operational notes
